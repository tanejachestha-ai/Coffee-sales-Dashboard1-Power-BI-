# Coffee-sales-Dashboard1-Power-BI
This project presents an interactive Coffee Sales Dashboard built in Power BI to analyze sales performance, product trends, and customer behavior. The report provides a complete overview of total sales, top-selling coffee products, weekday vs weekend performance, and customer patterns across different time ranges.

***************************************************************************************************************************************************************************************************************
Key Insights

Total Items Sold: 3547

Total Sales: 1.03M (Approx.)

Visual breakdown of coffee categories (Milk-Based, Black Coffee, Non-Coffee Drinks) by day.

Comparison of weekday vs weekend sales across multiple coffee types.

Analysis of customer types (Budget, Premium, Regular) across different time ranges (Morning, Afternoon, Evening, Night).

Donut chart showing number of orders for each coffee name.

Interactive slicers to filter products by name and coffee category.

********************************************************************************************************************************************************************************************************************

Features of the Dashboard

Clean and aesthetic coffee-themed UI

Dynamic charts: bar charts, donut chart, gauge chart, and KPIs

Interactive filters enabling quick drill-down into product-level insights

Data modeling and cleaning using Power Query

Calculated measures created using DAX
